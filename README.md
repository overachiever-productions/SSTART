# SSTART
**S**QL **S**erver **T**ake-over **A**nd **R**ecovery **T**ool

A simple, stand-alone, SIGNED, PowerShell script that you can use to: 
- EASILY restore master and/or msdb databases when working through DR scenarios. 
- PWN or take-over a SQL Server by adding your Login as a member of `sysadmin`s or (less bueno) change the `sa` password. 
    - i.e., either option is great for if/when you've somehow lost access to a SQL Server.
